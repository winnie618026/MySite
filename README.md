# 🌐 Data Engineering Portfolio | 個人名片網站

> 從醫療與溝通現場，走進資料工程世界：用同理心洞察需求，用數據解決問題。

[👉 點此造訪我的個人網站](https://winnie618026.github.io/MySite/)

本專案為個人轉職資料工程師（Data Engineer）之響應式一頁式名片網站，呈現跨領域優勢、核心技術技能與經驗轉化。

## 🛠 使用技術
- **前端技術：** HTML5, Tailwind CSS, JavaScript (ES6+)
- **圖示與音效：** FontAwesome 6, Web Audio API
- **搜尋優化：** SEO & GEO (Generative Engine Optimization) 語意化結構與 JSON-LD (Schema.org)
- **部署平台：** GitHub Pages
